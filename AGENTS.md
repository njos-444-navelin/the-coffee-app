# AGENTS.md

Instructions for AI coding assistants working in this repository.

Read `MANIFESTO.md` before proposing or implementing any product decision. It is binding.
See `docs/CONCEPT.md` for the product design; read it when working on product or architecture.
Read `docs/ARCHITECTURE.md` before writing or changing code; its stack choices and rules are binding and are not up for re-litigation. Anything it lists as still to choose, or as deliberately undecided, means ask; never pick silently.
Read `docs/RECOMMENDATIONS.md` when working on taste, matching, or anything that calls a language model.
If a request conflicts with it, point out the conflict and stop; do not comply silently or work around it.
If unsure whether something conflicts, ask.

Commits are signed off under the Developer Certificate of Origin (`git commit -s`).
